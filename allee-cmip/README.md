# Allee Critical Minerals Intelligence Platform

## Quick Start (30 seconds)
1. npm install
2. npm start
3. Open http://localhost:3000

## Add Cesium Token
In js/map.js, replace 'PASTE_YOUR_CESIUM_ION_TOKEN_HERE' with your token.
Get a free token at: https://ion.cesium.com/signup

## Deploy (Free)

### Netlify (easiest)
1. Drag this entire folder to app.netlify.com/drop
2. Done. You'll get a URL like allee-cmip.netlify.app

### Vercel
1. npm install -g vercel
2. vercel deploy
3. Done.
